# 🍀 Streamlit 로또 번호 생성기 (Lotto Number Generator)

클래스를 사용하지 않고 간결한 코드로 작성된, 실제 로또 공 색상이 반영되는 Streamlit 웹 애플리케이션입니다. 버튼을 누를 때마다 최대 5개까지 로또 번호 세트가 누적되어 화면에 표시됩니다.

## 📌 주요 기능
- **로또 번호 생성**: $1 \sim 45$ 범위의 중복 없는 6개 번호를 무작위로 추출합니다.
- **번호 누적 기능**: 생성 버튼을 계속 누르면 최대 5개 세트까지 화면에 누적됩니다.
- **실제 로또 공 색상 적용**: 구간별(1~10 노란색, 11~20 파란색, 21~30 빨간색, 31~40 회색, 41~45 초록색)로 실제 로또 공과 유사한 디자인을 적용했습니다.
- **간결한 코드 & 클래스 미사용**: 초보자도 쉽게 이해할 수 있도록 함수와 기본 제어문 위주로 가볍게 구현되었습니다.

---

## 🛠️ 설치 및 실행 방법

### 1. 사전 준비
Python이 설치되어 있어야 합니다. (Python 3.8 이상 권장)

### 2. 패키지 설치
프로젝트 폴더 내에서 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

### 3. 애플리케이션 실행
터미널에서 아래 명령어를 입력하여 Streamlit 앱을 실행합니다.
```bash
streamlit run app.py
```
